## What this is

This is the documentation for the **ultrabull stock analysis pipeline** — a Python system that pulls OHLCV data for a single NSE/BSE-style ticker (e.g. `HINDCOPPER.NS`), computes technical indicators, detects rule-based chart patterns, scores and filters them, converts the survivors into executable trade signals, runs those signals through an event-driven backtest simulator, and produces a mix of Markdown summaries, an Excel workbook, and matplotlib/mplfinance charts.

The entry point for a full run is `core/pipeline.py`. Running it end-to-end for one symbol looks like:

```bash
cd core
../venv/bin/python pipeline.py
```

The example output referenced throughout these docs (trade log, metrics, and all four chart types) is from a real run against `HINDCOPPER.NS`.

## Scope note

This documentation covers the **stock analysis / backtesting pipeline** only
(`core/`). It does not cover the Groww brokerage integration or the chainlit chat
agent — those are a separate, currently read-only portfolio-P&L path unrelated to
pattern detection or backtesting.
